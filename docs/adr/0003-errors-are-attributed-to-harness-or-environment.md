# Tool-call failures are Harness Faults or Environment Faults; only Harness Faults count

Every failed tool call is classified from its response body (not just the MCP error flag, since some servers report failures inside successful responses) and attributed either as a Harness Fault (wrong dataset, guessed key, bad arguments) or as an Environment Fault (network and TLS failures, timeouts, missing access). Only Harness Faults lower the Workflow Score. Without this, the same Harness scores differently depending on the network it runs on, for example behind a TLS-intercepting proxy, which makes scores incomparable across environments. Unrecognized failures default to Harness Faults, so attribution errs toward penalizing rather than excusing. A Sandbox Failure, where the evaluation machinery itself fails, is separate: that Run gets no score at all.
